# Approved Canvas reference catalog

Status: no approved asset files are included.

These are reference assets, not working app source. Use only actual approved
material. Store client assets here only when repository permissions and client
policy permit; otherwise record an authorized retrievable reference and its version.

## Locations

- [templates/](templates/README.md): approved complete screen baseline YAML.
- [controls/](controls/README.md): approved configured controls or reference screens.
- [theme/](theme/README.md): approved theme definition and documented usage.
- [mockups/](mockups/README.md): screen-specific HTML mockups and approval evidence.

For template/control YAML, record authoring/schema compatibility, required control
versions, component names, theme, data/API dependencies, and any excluded demo
controls. A file's presence or use in another screen does not establish approval.

For each mockup, record target screen, intended window sizes and significant
states, baseline asset versions, and known Canvas limitations. Drafts must be
explicitly marked unapproved. Document approved differences before implementation.

When an asset changes, obtain required approval, register the new version and
superseding evidence, and assess dependent screens. Do not silently refresh the
baseline from a working screen. Missing assets block only affected work.
